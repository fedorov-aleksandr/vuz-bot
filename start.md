Инструкция по запуску проекта (локально и в Docker).

1) Требования
- Python 3.10+
- Установленный `uv` (если хотите использовать вместо pip локально) — опционально

2) Установка зависимостей (локально)

Если вы хотите установить зависимости через `uv` (рекомендуется по вашему запросу), установите `uv` согласно документации проекта Astral, затем в каталоге проекта выполните:

```
uv install
```

Если `uv` недоступен, используйте pip:

```bash
python -m pip install -r requirements.txt
```

3) Запуск локально

```bash
# Установите переменную окружения с токеном бота (рекомендуется)
export BOT_TOKEN="<ваш_токен>"  # linux/mac
setx BOT_TOKEN "<ваш_токен>"    # windows (или используйте PowerShell $env:BOT_TOKEN)

python main.py
```

4) Сборка и запуск в Docker

Сборка образа:

```bash
docker build -t vuz-bot:latest .
```

Запуск контейнера (рекомендуется с политикой рестарта):

```bash
# Перед запуском передайте токен через переменную окружения
docker run -d --name vuz-bot --restart unless-stopped -e BOT_TOKEN="$BOT_TOKEN" vuz-bot:latest
```

Полезно: флаг `--restart unless-stopped` автоматически перезапустит контейнер после перезагрузки хоста или кратковременных сетевых сбоев.

5) Поведение при перезагрузке роутера / обрыве интернета
- Внутри контейнера запущен скрипт `start.sh`, который перезапустит `main.py`, если процесс завершится по ошибке.
- Если соединение теряется, Aiogram обычно пытается переподключиться; если процесс упадёт — `start.sh` перезапустит его.
- Для гарантированного восстановления после перезагрузки машины используйте `docker run --restart unless-stopped`.

6) Дополнительные идеи

- Использовать `docker-compose` и healthcheck для более надежного мониторинга и рестартов.
